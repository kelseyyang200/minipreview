# MiniPreview

一个轻量、无构建依赖的视频审片与时间点批注工具。打开单个 HTML 文件即可加载视频、定位时间点、记录修改意见，并将批注导出或生成分享链接。

> 当前版本是可运行的前端原型，适合快速演示审片交互和验证协作流程。

## 功能

- 支持本地视频、多个本地视频以及直链视频
- 时间轴定位、进度预览和时间点标签
- 批注的添加、编辑、跳转与删除
- 播放/暂停、前后 5 秒、倍速和逐帧模式
- 多视频连续播放与分段时间轴
- 批注文本导出、复制和带画面的长图导出
- 将在线视频地址与批注编码为分享链接
- 针对企业微信微盘链接的辅助审片模式
- 拖拽、双击和文件选择等多种视频载入方式
- **左侧边栏工作目录（多根工作区）**：像 VSCode 一样可同时添加多个本地项目目录，每个目录分组显示、可折叠；往里面丢视频后可直接在侧边栏点开播放，支持子目录扫描与文件名筛选，也可按目录一键顺序加载全部
- **最近打开**：自动记录最近打开的项目（目录视频 / 本地文件 / 直链 / 微盘），点击即可重新打开，刷新或重启浏览器后仍然保留
- **批注本地缓存**：批注按项目自动保存到浏览器 IndexedDB，重新打开同一项目时自动恢复，不再因刷新丢失

## 侧边栏与记忆功能说明

- 需要 **Chrome / Edge（86+）** 浏览器（依赖 File System Access API 读取本地文件夹）；其他浏览器下侧边栏仍可见，但目录功能会提示不支持。
- 所有数据（文件句柄、最近记录、批注）都只保存在**本地浏览器**（IndexedDB / localStorage），不上传任何服务器。
- 浏览器重启后首次访问工作目录需要**重新授权一次**（点击侧边栏的「重新授权」按钮即可），这是浏览器的安全机制。
- 从「本地文件」按钮或拖拽打开的视频同样会被记住，重开时若失去授权会引导重新选择文件，批注自动按文件名匹配恢复。

## 快速开始

项目不需要安装依赖，也不需要编译。

1. 下载或克隆仓库。
2. 用现代浏览器打开 `index.html`。
3. 选择本地视频，或输入可直接播放的 `.mp4` / `.webm` 视频地址。
4. 在时间轴双击或按 `M` 添加批注。

也可以在仓库目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` | 后退 5 秒 |
| `→` | 前进 5 秒 |
| `M` | 在当前时间添加批注 |
| `F` | 开启 / 关闭逐帧模式 |
| `Enter` | 保存批注并继续播放 |
| `Shift + Enter` | 在批注中换行 |
| `Esc` | 保存当前批注 |

## 技术实现

- 原生 HTML、CSS 与 JavaScript
- HTML5 `<video>` 播放能力
- Canvas 视频帧截取与长图导出
- Blob / Object URL 本地媒体处理
- URL 参数承载可分享的批注数据
- File System Access API 读取本地工作目录（`showDirectoryPicker` / `showOpenFilePicker`）
- IndexedDB 持久化文件句柄、最近记录与批注；localStorage 保存界面偏好

所有本地视频都只在浏览器中读取，不会由本项目上传到服务器。

## 当前限制

- 这是纯前端原型，没有账号、数据库和服务端持久化；记忆功能依赖浏览器本地存储（IndexedDB），更换浏览器或清除站点数据后记录会丢失。
- 工作目录与文件重开功能依赖 Chromium 系浏览器（Chrome / Edge 86+），Firefox / Safari 暂不可用。
- 浏览器安全机制要求重启后对本地目录重新授权一次（点击一次按钮即可）。
- 在线视频需要可直接访问的媒体地址，并受来源站点的跨域策略影响。
- 分享链接只包含视频地址和批注，不包含本地视频文件本身。
- 超长批注数据会增加分享 URL 的长度，生产环境建议改为服务端存储。
