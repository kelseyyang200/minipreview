# MiniPreview

一个轻量、无构建依赖的视频审片与时间点批注工具。打开单个 HTML 文件即可加载视频、定位时间点、记录修改意见，并将批注导出或生成分享链接。

> 当前版本是可运行的前端原型，适合快速演示审片交互和验证协作流程。

## 功能

- 支持本地视频、多个本地视频以及直链视频
- 时间轴定位、进度预览和时间点标签
- 批注的添加、编辑、跳转与删除
- 播放/暂停、前后 5 秒、倍速和逐帧模式
- 多视频连续播放与分段时间轴
- 批注文本导出、复制和带画面的长图导出
- 将在线视频地址与批注编码为分享链接
- 针对企业微信微盘链接的辅助审片模式
- 拖拽、双击和文件选择等多种视频载入方式

## 快速开始

项目不需要安装依赖，也不需要编译。

1. 下载或克隆仓库。
2. 用现代浏览器打开 `index.html`。
3. 选择本地视频，或输入可直接播放的 `.mp4` / `.webm` 视频地址。
4. 在时间轴双击或按 `M` 添加批注。

也可以在仓库目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` | 后退 5 秒 |
| `→` | 前进 5 秒 |
| `M` | 在当前时间添加批注 |
| `F` | 开启 / 关闭逐帧模式 |
| `Enter` | 保存批注并继续播放 |
| `Shift + Enter` | 在批注中换行 |
| `Esc` | 保存当前批注 |

## 技术实现

- 原生 HTML、CSS 与 JavaScript
- HTML5 `<video>` 播放能力
- Canvas 视频帧截取与长图导出
- Blob / Object URL 本地媒体处理
- URL 参数承载可分享的批注数据

所有本地视频都只在浏览器中读取，不会由本项目上传到服务器。

## 当前限制

- 这是纯前端原型，没有账号、数据库和服务端持久化。
- 刷新页面后，本地会话中的批注不会自动保留；可先导出或生成分享链接。
- 在线视频需要可直接访问的媒体地址，并受来源站点的跨域策略影响。
- 分享链接只包含视频地址和批注，不包含本地视频文件本身。
- 超长批注数据会增加分享 URL 的长度，生产环境建议改为服务端存储。
